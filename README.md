# Student Management System

A menu-driven Java console application for registering and managing students. The current version implements student registration, display, ID/name searches, average filters, and sorting. Course/skill reports, performance statistics, and bonus marks are not implemented yet.

## Requirements

- Java Development Kit (JDK) 8 or later

## Compile and run

Open a terminal in the project directory and run:

```powershell
javac Student.java StudentManagementSystem.java Main.java
java Main
```

The application starts with an empty student list. Choose an option from the menu to register students, view reports, or exit with `0`.

## Features

- Register students with a unique ID, age, courses/marks, and skills
- Search, filter, and sort student records
- Course and skill reports (planned)
- Performance statistics and bonus marks (planned)
